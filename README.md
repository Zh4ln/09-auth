# 09-auth — NoteHub (Next.js)

Отдельная девятая домашка GoIT. Восьмая домашка не изменяется.

## Первый запуск

1. Открой папку `09-auth` в VS Code.
2. Выполни `npm install`.
3. Выполни **`npm run sync:goit-api`**. Команда загрузит из официального репозитория GoIT ветку `hw-09-api-files` и **заменит всю папку `app/api` на оригинальные файлы GoIT**. Нужен установленный Git и доступ к GitHub. Эти файлы не редактируй. Пока команда не выполнена, в проекте находится только совместимый резервный прокси, **не официальный код GoIT**.
4. Создай `.env.local` в корне проекта:

   ```env
   NEXT_PUBLIC_API_URL=http://localhost:3000
   ```

   Старый токен NoteHub из прошлых домашних работ **не нужен**.
5. Запусти `npm run dev` и открой `http://localhost:3000`.
6. Перед публикацией: `npm run build` и `npm run lint`.

## Что проверить

- Регистрация нового аккаунта /sign-up и вход /sign-in.
- После входа открывается /profile. Обновление страницы не разлогинивает пользователя.
- /profile/edit меняет только username и возвращает в профиль.
- Выход очищает авторизацию и перенаправляет на /sign-in.
- Гость не может открыть /notes/filter/all и /profile напрямую.
- Авторизованный пользователь при открытии /sign-in попадает в /profile.
- /notes/filter/all, поиск, фильтрация, пагинация, создание и удаление заметок.
- View details из списка (модальное окно) и прямой переход /notes/ID (полноценная страница).

## Vercel

Создай **новый** проект из репозитория `09-auth`; Framework — Next.js. В Environment Variables укажи `NEXT_PUBLIC_API_URL` равным **фактическому production URL сайта**, например `https://09-auth-...vercel.app` без последнего `/`. После изменения переменной нужен новый деплой.

`NEXT_PUBLIC_`-переменные публично доступны в JavaScript. Не записывай туда пароли, cookie или секретные токены. `.env.local` защищён `.gitignore`.

## Ограничения проверки сборки

Код проверен статически по TypeScript/ESLint с временными типами для Next.js/Zustand. Настоящий `next build` и работа нового бекенда не подтверждены до запуска на твоём компьютере и замены `app/api` на официальные файлы.
